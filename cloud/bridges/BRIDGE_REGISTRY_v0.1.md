# LIFE-CODE / Reality-Code Bridge Registry v0.1

Purpose: durable, evidence-bounded registry of claims connecting LIFE-CODE and Reality-Code. One project must never silently validate the other. Each bridge is assigned a level and explicit evidence status.

## Bridge levels

- **L0 FORMAL** — mathematical identity/isomorphism/equivalence proved from frozen definitions. No empirical common-substrate claim.
- **L1 SYNTHETIC EMPIRICAL** — same frozen operator/scorer succeeds on independently generated synthetic systems under blind/control conditions.
- **L2 REAL-DOMAIN EMPIRICAL** — same preregistered operator produces null-adjusted predictive/transfer evidence in both real domains.
- **L3 CROSS-DOMAIN GENERALIZATION** — parameters/operators frozen in one domain predict an independently held-out real domain without retuning.
- **L4 COMMON-MECHANISM CANDIDATE** — multiple independent L2/L3 results plus discriminating tests against alternative mechanisms. Still not ontology proof.

## Operating rule

A higher bridge level may use lower-level proved facts but may not inherit their evidentiary status. Formal equivalence is not empirical mechanism evidence. Synthetic success is not real-domain validation. Real-domain correlation is not a common physical substrate.

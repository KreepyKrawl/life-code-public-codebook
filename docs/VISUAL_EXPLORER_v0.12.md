# LIFE-CODE Visual Explorer 0.12

The public Explorer implements the recovered character-creator direction as a 2D client of traceable source records. Scientific Codebook Core remains v0.11. No scientific database, released result, or historical record is changed by this interface release.

## Shipped behavior

- Central Heliconius-inspired synthetic specimen with selectable forewing bands, hindwing bars, and unsupported margin spots.
- Color and visibility controls, four palettes, side-by-side comparison, mask view, zoom, and reset.
- Discover explanations and questions for younger visitors; Research exposes the full original region record and provenance chain.
- Downloadable variation JSON includes source-file SHA-256, archived packet identifier/hash, changes, rendering scope, and explicit null score. Changes are tab-local until exported.
- The original v0.6 HTML prototype is preserved byte-for-byte in program_sources. SVG wing and band geometry and packet records are extracted from that file into data/explorer-fixture.js.
- Real BENCH-P01A manifest is linked separately, with its prepared-test status made explicit.

## Scientific interpretation

The fixture is synthetic. Original RETRODICTED / SCIENTIFIC fields describe the archived contract demonstration, not an actual species prediction. Source paths terminate at SYNTHETIC_ONLY or insufficient evidence. User variations execute no model, carry no scientific score, and make no genotype or phenotype probability claim. Veins, scales, lighting, and body styling are illustrative. Existing rRNA and FBA sequence evidence does not establish a causal bridge to butterfly traits.
